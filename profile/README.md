### 🛠️ What This Org Is For

This GitHub organization powers **internal development**, including:

#### 🌱 Client Web App (Private MVP)

A private app where clients access annotated, interactive feedback and personalized training tools.

**As of October 4, 2025:**

- **Frontend**
  - React, Zustand, shadcn/ui, Tailwind
- **Backend**
  - Node.js (Express), hosted on Render
  - PostgreSQL (Prisma), Airtable via API
  - AWS S3
- **Other**
  - Auth0 for authentication
  - Manual/informal testing
  - 🦆 Rubber ducking + Cursor, ChatGPT, dev friends
  - Vite, pnpm monorepo

**Coming Soon:**

- Native mobile apps (React Native via Expo)
- AI/ML (but keeping human expert in the loop for important client feedback)
- More rigorous statistics and measurement of accent
- More structured testing + deployment
